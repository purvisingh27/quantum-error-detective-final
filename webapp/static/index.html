Read the results responsibly

Readout mitigation estimates measurement bias; it does not undo gate errors. Noise diagnosis is heuristic. ZNE extrapolation can be unstable. Raw confidence intervals use the Wilson method. The mitigated interval bootstraps observed counts but does not include calibration-matrix uncertainty. Results can vary with shots and seed.
